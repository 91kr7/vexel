# Modules

| Module | Responsibility | Index |
|--------|----------------|-------|
| ui-library | The internal, domain-agnostic UI library (`client/src/ui/`): design tokens, the glass material, layout, navigation, control, metric and feedback primitives — the only place allowed raw DOM tags and CSS. | `ui-library/index.md` |
| app-shell | The application shell that composes the UI library: navigation data, the "Vexel — Docker Control" shell, and the application-wide confirmation/error/progress/connection/event services. | `app-shell/index.md` |
| docker-access | Server-side Docker access layer: the Engine API client (unix/TCP+TLS/ssh, version negotiation, typed errors) and the local `docker`/`compose`/`buildx` CLI runner — shared by every future domain area that talks to Docker. | `docker-access/index.md` |
| connectivity | Daemon reachability, negotiated API version and CLI/plugin availability: server status service and endpoint, and the client's typed status reader. | `connectivity/index.md` |
| events | The live daemon event stream: server subscription/republish/backlog, its SSE endpoint, and the client's subscription plus object-type invalidation registry. | `events/index.md` |
| local-persistence | Local, per-user persistence (preferences, console history, analysis-cache index) and host-path validation: the local store, the content-addressed analysis cache, the host-path validator, their endpoints, and the client's preferences client/hook. | `local-persistence/index.md` |
| containers | Container list, creation, lifecycle, inspection/configuration, logs, live statistics and processes: the Engine API listing/lifecycle/prune/inspect/config service and its bounded CPU/memory sampler, the creation service with image resolution and pull, the log- and stats-streaming services, the process listing, their endpoints, the client's containers data clients/hooks, the Containers screen with its create/run form, and its detail panel with the logs, stats and processes views. | `containers/index.md` |
| images | Image list and registry-facing actions: the Engine API listing/inspect service, the pull/push/tag/untag/remove/prune transfer service, their endpoints, the client's images data clients/hooks, the Images screen and its inspect detail panel. | `images/index.md` |
| image-analysis | Per-image layer stack, per-layer changesets, and runtime-independent filesystem browsing with in-tree file operations: manifest/config-derived layer metadata, cross-image shared-layer detection, cached and cancellable per-layer changeset computation with OCI whiteout awareness, cached and cancellable filesystem extraction (an unstarted intermediate container, cleaned up whatever happens) with lazy tree reads, entry metadata/content/search/export over the extracted tree with containment against traversal and escaping symlinks, and their endpoints. | `image-analysis/index.md` |
| server-app | The server entrypoint that composes every server module into one running Express app. | `server-app/index.md` |
