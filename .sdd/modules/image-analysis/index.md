# image-analysis — Index

| Component | Type | Path | Responsibility | Spec |
|-----------|------|------|-----------------|------|
| LayerMetadataService | backend service | `server/src/image-analysis/layer-metadata-service.ts` | Assembles an image's ordered layer stack from its manifest/config (RootFS diff ids) and history: digest, uncompressed size, empty-layer flag and originating instruction/command, marking anything the daemon cannot provide as explicitly unavailable | `specs/layer-metadata-service.md` |
| SharedLayerService | backend service | `server/src/image-analysis/shared-layer-service.ts` | For a set of diff ids, finds the other local images that reference the same content-addressed layer | `specs/shared-layer-service.md` |
| ChangesetService | backend service | `server/src/image-analysis/changeset-service.ts` | Computes per-layer added/modified/deleted paths by reading an exported image tarball layer by layer, honouring OCI whiteout markers; cached, progress-reporting and cancellable | `specs/changeset-service.md` |
| FilesystemExtractionService | backend service | `server/src/image-analysis/filesystem-extraction-service.ts` | Creates a container from an image without ever starting it, exports and indexes its merged filesystem into a flat entry list carrying full POSIX metadata, removes the container whatever happens, keeps the raw archive cached for later reads, and serves lazy per-directory reads and the startup cleanup sweep; cached across restarts, progress-reporting and cancellable | `specs/filesystem-extraction-service.md` |
| FilesystemContainment | backend utility | `server/src/image-analysis/filesystem-containment.ts` | Resolves a tar entry name, a symlink target or a request path against the extracted tree's root, refusing one that carries an absolute path or a `../` segment attempting to leave it | `specs/filesystem-containment.md` |
| FilesystemEntryService | backend service | `server/src/image-analysis/filesystem-entry-service.ts` | Reads one extracted entry's full metadata: size, formatted permissions, uid/gid, modification time, type and symlink target | `specs/filesystem-entry-service.md` |
| FilesystemContentService | backend service | `server/src/image-analysis/filesystem-content-service.ts` | Reads a file's preview content from the cached archive with text/hex auto-detection and an operator override, truncated past a byte bound | `specs/filesystem-content-service.md` |
| FilesystemSearchService | backend service | `server/src/image-analysis/filesystem-search-service.ts` | Name/path fragment search across an extracted tree's indexed entries, bounded in result count | `specs/filesystem-search-service.md` |
| FilesystemExportService | backend service | `server/src/image-analysis/filesystem-export-service.ts` | Streams a single entry's file content, or a subtree freshly built as a tar archive, as a browser download; previews a subtree's contents before the download starts | `specs/filesystem-export-service.md` |
| ImageDiffService | backend service | `server/src/image-analysis/image-diff-service.ts` | Compares two images' merged filesystems — extracting each side first, reusing a cached extraction — into added/removed/changed paths with the nature of a change (content, size, mode, ownership, symlink target); cached in-memory per compared pair for lazy per-directory tree reads with roll-up counts, progress-reporting and cancellable | `specs/image-diff-service.md` |
| Image analysis endpoints | REST endpoint | `server/src/image-analysis/image-analysis-routes.ts` | Exposes the layer stack (with shared-layer markers), a cancellable changeset-analysis progress stream, the filesystem extraction/tree-read pair, the in-tree metadata/content/search/export endpoints, and the cross-image filesystem diff stream/tree-read pair, to the client | `specs/image-analysis-endpoints.md` |
